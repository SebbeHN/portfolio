# Sebastian Holmberg Nilsson - Portfolio

Personlig portfolio för Sebastian Holmberg Nilsson, junior systemutvecklare baserad i Skåne och med fokus på Malmö och Lund.

## Om projektet

Portfolion presenterar Sebastians projekt, teknikstack och kontaktuppgifter. Den innehåller också en nedladdningsbar PDF-version av CV:t.

## Teknik

- React
- Vite
- JavaScript
- Responsiv CSS
- Google Fonts

## Utvalda projekt

- [Öl-priser](https://github.com/SebbeHN/olpriser) - hitta och sortera ölpriser runt om i Malmö.
- [BeUniq](https://www.beuniq.se) - webbplats för ett resebolag där besökare kan önska resor och få offerter.
- [AI Football Scout](https://github.com/SebbeHN/ai-football-scout) - AI och analys med fokus på fotbollsscouting.

## Kom igång lokalt

Installera beroenden:

```bash
npm install
```

Starta utvecklingsservern:

```bash
npm run dev
```

Skapa en produktionsbuild:

```bash
npm run build
```
